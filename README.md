## Background
Data Tour Notebooks are Python-based notebooks created to provide guided tutorials for accessing and using NOAA data from NCEI servers, AWS S3 Buckets, and Google Cloud Buckets. Each notebook will focus on a different product and demonstrate basic tools for extracting and working with the data. These notebooks are built using the Google Colaboratory environment. They can also be used by loading a JupyterHub environment in Binder or cloning the notebooks to your machine.

## Folders
Each folder within this repository corresponds to a specific NCEI product. Within each folder, there will be a readme with information on how to clone the notebooks or use them within the Google Colaboratory environment. Similar information is found below.

## Install
Follow the instructions in the readme for each product, located within each product folder. This will explain how to properly install and use the codes within other environments.

## Usage
Each product contains different usage instructions, which can be found in the product readme within their respective folder. Below we outline the three different methods that the codes may use.
### Colaboratory
Clicking the "Open in Colab" button at the top of the product specific README will launch a Google Colaboratory environment in your browser. You can open, run, and modify any of the included Data Tour Notebooks. You can also download the .ipynb file and upload to Google Colab to run the notebook.
### Binder
Some of the Data Tour Notebooks may include a “Launch Binder” button at the top of the product specific README. In this environment, you can open, run, and modify the Data Tour Notebook, as well as create your own.
### Local Repository
This repo must be installed before using the notebooks locally. You will need to have Anaconda or Miniconda installed. Create a python environment, activate it, and install all dependencies in the environment. Open Jupyter notebooks to use these products.
